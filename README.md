# Python CRUD Application

## 📌 Project Overview
This project is a Python-based CRUD (Create, Read, Update, Delete) application developed as a final practical assignment.  
The application demonstrates how CRUD functionality can be implemented using different data storage approaches.

## 🧠 Key Features
- CRUD operations implemented step by step
- Modular code structure
- Clear separation of logic
- Console-based interaction

## 🛠️ Technologies Used
- Python
- CSV file handling
- MySQL (via mysql-connector)
- Basic SQL queries

## 📂 Project Structure
- `list_CRUD.py` – CRUD operations using in-memory lists
- `file_CRUD.py` – CRUD operations using CSV files
- `db_CRUD.py` – CRUD operations using a MySQL database
- `main.py` – Application entry point
- `my_pets.csv` – Sample data file

## 🔄 Development Approach
The project was developed incrementally:
1. First, CRUD functionality was implemented using Python lists.
2. Next, file-based CRUD was added using CSV files.
3. Finally, database-based CRUD was implemented using MySQL.

This approach helped to understand data persistence concepts and differences between storage methods.

- Working with files and databases
- Structuring Python projects
